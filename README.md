## 功能

- **多会话** — 每个角色有独立的设定、头像和聊天记录
- **称呼系统** — AI 会用你指定的昵称叫你
- **戳一戳** — 自定义戳一戳文案，双向互动
- **主动消息** — AI 会在 15-45 分钟内随机主动找你聊天
- **碎碎念** — AI 的心里话，仅你可见
- **已读不回** — AI 有时候会假装没看到你的消息
- **屏幕共享** — OCR 识别屏幕内容，黑名单自动挂断
- **引用回复 & 重新生成** — 长按消息操作，版本可切换
- **MCP 工具链** — 支持导入/粘贴/远程连接，AI 可调用外部工具
- **拉黑 & 回收站** — 已删除内容 30 天内可恢复
- **日间/夜间模式** — 浅蓝主题，跟随系统或手动切换
- **导入/导出** — 聊天记录 JSON 格式备份
- **新手引导** — 首次进入了解你的喜好
- **使用时长提醒** — 盯屏幕久了会轻轻戳你一下
- **隐私优先** — 所有数据存储在手机本地，不上传任何服务器

- Room (v12) + Retrofit
- ML Kit OCR
- MCP (Model Context Protocol)
